### Prosjekter jeg er stolt av

**[Atlas](https://github.com/kartAI/Atlas)**  
KI-assistert kartverktøy for konsekvensutredninger, bygget hos [kartAI/Norkart](https://github.com/kartAI). Assistenten bruker MCP-verktøy for å slå opp geodata, lese dokumenter fra Blob Storage og tegne resultater rett i kartet. Mye av tiden min går med til å få KI-en til å faktisk bruke verktøyene — og ikke bare gjette.  
`React` `Python` `MCP` `PostGIS` `Copilot SDK` `Azure`

**[SafeShelter](https://github.com/TriggeredBanana/SafeShelter)**  
Beredskapsapp som hjelper deg finne nærmeste tilfluktsrom, brannstasjon eller sykehus i Agder. Sanntidsposisjonering, ruteberegning, flomsoner fra NVE og en KI-assistent som kan svare på nødrelaterte spørsmål. Gruppeprosjekt ved UiA.  
`Leaflet.js` `Node.js` `Supabase/PostGIS` `OSRM`  
[Prøv live-demoen](https://safeshelter-iilu.onrender.com/index.html)
